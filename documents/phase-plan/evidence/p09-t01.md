# P09-T01 — independent A/B/C topology

Date: 2026-11-24. Branch: `phase-09`. Base: Phase 08 plus token tooling commit `435c8d2`.

## Implementation

- `deploy/compose.yml` no longer gives services global container names. Compose
  project `nexora-a|b|c` scopes networks and PostgreSQL/SeaweedFS volumes.
  Identical image code can be reused; runtime state is never shared.
- Each ignored instance env has distinct DB credentials, published localhost
  ports, `keycloak-a|b|c` issuer, S3 bucket names and a per-instance rendered
  APISIX file. The Keycloak realm is named `nexora` within each separate
  PostgreSQL cluster; its issuer differs by instance. Admin, staff and approver
  boot users and client credentials are generated outside Git.
- `seed-abc.mjs` verifies the demo Compose project label before idempotently
  creating organization, three role memberships, product, local lot, warehouse
  and adjacent partner stubs. It creates no stock movement. Lô A/B/C have
  distinct local IDs and a fixture origin A; inbound provenance mapping remains
  T05 work. `abc-reset.mjs` refuses a missing `DEMO_ONLY=true`, any project
  outside A/B/C and env identity mismatch.
- `deploy/abc-topology.md` contains prepare/up/seed/drill/reset commands and
  the local-only HTTP boundary. `.gitattributes` keeps shell scripts LF on
  Windows checkouts; without it the mounted PostgreSQL bootstrap script failed
  under `/bin/sh`.

## Verification

- `node --test deploy/config.test.mjs tests/e2e/abc-topology.test.mjs`:
  17 passing checks, including three Compose graphs with disjoint
  issuer/ports/volumes/routes and reset refusal.
- `npm test`, `npm run lint`, `npm run typecheck`, `git diff --check`:
  passed locally. The typecheck script runs `next typegen` first, as required
  for generated `LayoutProps` in a fresh checkout.
- Live drill on three disposable Compose projects: all migrated and booted;
  seed A/B/C completed. `pg_control_system().system_identifier` returned
  three distinct identifiers. Keycloak discovery returned three distinct
  issuer URLs; project-scoped PG and SeaweedFS volumes existed. All three
  app DBs had administrator/staff/approver, expected partners and no opening
  movement. With B stopped, gateway B was unavailable while A and C each
  created, read and confirmed a GoodsReceipt through their own gateway.
  Each receipt created one persistent `trading.receipt.confirmed.v1` outbox
  row. B restarted and retained its organization and zero movements.
- A guarded reset of B removed its containers and volumes while A/C gateways
  still returned HTTP 200. The script then reset A and C; no demo project
  containers or volumes remained. All three projects were test-only.
- The drill is reproducible with `DEMO_ONLY=true node tests/e2e/abc-topology-drill.mjs`;
  generated env/manifest/result files are Git-ignored. It intentionally leaves
  A/C with one receipt each, so reset and re-seed before the canonical G09
  quantity journey.

## Boundary

This proves local business availability and durable local outbox storage while
B is down. It does not claim transfer delivery, technical ACK, receiving
confirmation or cross-instance trace. T02–T09 implement and verify those
contracts and effects.
