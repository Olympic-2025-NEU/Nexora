# P12-T02 — Archive export lifecycle

Date: 2026-11-27. Branch: `phase12/p12-t02-archive-export`.

## Implemented

- `workers/archive-export.ts` — polls **delivered** outbox rows (after commit), writes private S3 JSONL, creates append-only `platform.core_record` kind `archive_manifest` with JCS checksum + checkpoint watermark. Does **not** run inside confirm transactions.
- Worker wire: `worker/entrypoint.js` 30s loop; Compose worker gets `S3_*`; `deploy/config.mjs` worker profile requires S3 private bucket.
- Metrics: `archive_manifest_count`, `archive_export_lag_seconds` on worker `/metrics`.
- Query CLI (inside the matching worker container): `docker exec nexora-a-worker-1 node deploy/scripts/archive-query.mjs a --batch <uuid>` verifies manifest/object SHA-256 and reports bounded source event IDs by batch/time/issuer; it does not disclose raw event payload.
- Unit/behavior: `tests/platform/archive-export.unit.test.ts`, `archive-export.behavior.test.ts`, `archive-query.test.mjs` cover stable checksum, more than 1,000 events, a failed partition write and tampered archive detection.

2026-11-28: checkpoint pagination and partition ordering were repaired in source. Live worker restart, late/duplicate delivery and controlled rebuild after corrupted object remain to be demonstrated on a coherent Phase 12 runtime; see [recheck](p11-p12-remediation-2026-11-28.md).

## Non-claims

- Not a lakehouse; JSONL + manifest query only.
