# P03-T02 — Unit of Work và ghi đồng thời

**Ngày:** 2026-11-19

**Nhánh:** `phase03/p03-t02-unit-of-work`

**Trạng thái:** PASS cho primitive T02; G03 còn phụ thuộc T03–T08.

## Quyết định và phạm vi

`Transaction.run` dùng Prisma interactive transaction mức Serializable. Mọi repository trong callback nhận cùng `Prisma.TransactionClient`, với `maxWait=2s`, `timeout=10s` mặc định. Chỉ P2034/SQLSTATE 40001/40P01 được retry tối đa 2 lần; lỗi domain/unique không retry, hết lượt trả `TRANSACTION_CONFLICT`, quá hạn trả `TRANSACTION_TIMEOUT`. Callback phải chỉ chứa DB work, không gọi mạng/storage trước commit.

Policy aggregate là compare-and-swap theo `id,version`; tồn kho là update có điều kiện đủ số dư. Khi cần ghi nhiều dòng, sắp khóa theo khóa chuẩn `(warehouse_id,batch_id)` trước khi update. Chi tiết được ghi ở `database.md` §3.

## Kiểm chứng đã chạy

Lệnh: `npm run test:transaction:unit`, `npm run test:platform:transaction` trên PostgreSQL 17.6 pin digest, `npm run build`, `npm run typecheck` sau build, `npm run lint`, `npm test`. Tất cả PASS. Script runner chọn Git Bash trên Windows và Bash hệ thống trên Linux.

| Phép thử | Kết quả |
| --- | --- |
| Retry P2034/40001/40P01 và dừng đúng giới hạn | 4/4 unit tests PASS |
| Inject failure sau aggregate, stock, movement, audit, outbox | 5/5 rollback; aggregate vẫn Draft, balance 10, movement/audit/outbox = 0 |
| Command thành công | aggregate Confirmed/version 2, balance 4, mỗi movement/audit/outbox = 1 |
| Hai writer cùng trừ 6 từ balance 8 | Đúng một command confirm; balance 2, mỗi log/event = 1 |
| Hai writer nhận thứ tự hai stock key ngược nhau | Cả hai commit; đo 57 ms trên máy local, `pg_stat_database.deadlocks` không tăng |
| Timeout Prisma 50 ms với `pg_sleep(0.2)` | `TRANSACTION_TIMEOUT`, callback chạy 1 lần |

Bảng `tx_spike_*` được tạo chỉ trong database test tự hủy và **không** là migration sản phẩm. Audit là bảng `platform.audit_log` thật. Bài kiểm chứng này đo transaction primitive; P04/P06/P07 vẫn phải kiểm aggregate, stock, movement và outbox thật khi các bảng đó ra đời.
