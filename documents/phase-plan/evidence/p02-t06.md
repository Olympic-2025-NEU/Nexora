## HTTPS Configuration

### APISIX config.yaml (P02-T06 additions)

```yaml
apisix:
  node_listen:
    - port: 9080   # HTTP (local smoke / redirect)
    - port: 9443   # HTTPS (P02-T06)
  ssl:
    ssl_trusted_certificate: /usr/local/apisix/conf/certs/local.pem
```

### Compose gateway ports

```yaml
ports:
  - "127.0.0.1:${GATEWAY_HTTP_PORT:-19080}:9080"
  - "127.0.0.1:${GATEWAY_HTTPS_PORT:-19443}:9443"
```

Both ports are loopback-only (`127.0.0.1:`). `0.0.0.0` binding is never used.


Generates `deploy/certs/local.pem` and `deploy/certs/local-key.pem`.  
Both are gitignored via `deploy/certs/.gitignore`.

### Why mkcert?

- Local CA trusted by OS, browsers, curl, Node.js (with `NODE_EXTRA_CA_CERTS`).
- No `--insecure` flags needed in CI/smoke scripts.
- Prevents Keycloak OIDC issuer scheme drift (Keycloak requires `https://` in production).

## SSRF Allowlist

`platform/security/ssrf.ts` — `validatePartnerUrl(url)` enforces:

1. **HTTPS only** — `http://`, `ftp://`, `file://` etc. throw `SsrfError("SCHEME_NOT_HTTPS")`.
2. **No localhost** — `localhost` throws `SsrfError("PRIVATE_HOST")`.
3. **No private IPv4** — RFC 1918 (10.x, 172.16-31.x, 192.168.x), loopback (127.x), link-local (169.254.x), CGNAT (100.64.x) blocked.
4. **No private IPv6** — `::1`, `fe80:`, `fc00:`, `fd*` blocked.
5. **No single-segment hostnames** — Docker internal names (e.g. `keycloak`, `postgres`) without dots throw `SsrfError("INTERNAL_HOSTNAME")`.

Applied when creating/updating `PartnerConnection.endpointUrl` and `outboundTokenUrl`.

## CORS Notes for Bearer

Bearer tokens use the `Authorization` request header, which is a "non-simple" CORS header.

For the APISIX gateway:
- Preflight `OPTIONS` requests must be handled (APISIX CORS plugin or dedicated route).
- The ERP Next.js app sends OIDC redirect — no cross-origin Bearer call from browser directly.
- For DX-Lab (SPA) or future partner portals, CORS headers must include `Authorization` in `Access-Control-Allow-Headers`.
- Gateway admin plane (`enable_admin: false`) is not exposed; Keycloak admin port is internal-only.

| Service | Port | Binding | Access |
|---|---|---|---|

| Flowable REST | 8080 | internal network | Only via basic auth on `internal` |
