# P10-T01 — Provider, data policy and failure isolation

Date: 2026-11-26. Branch: `phase-10`. Scope: optional Python adapter, local Ollama decision [D09](../../adr/0009-ai-provider.md), bounded fact-only inference contract. No live model answer is claimed here; model quality and A/B/C AI journey are P10-T03/G10.

## Implementation

- `services/ai/{app,config,provider}/` has no DB or business client, only a fixed internal Ollama destination. Default provider is `none`; `ollama` requires an out-of-repo internal token. The HTTP adapter rejects extra fields, >4096-byte requests, >10 facts, common contact/credential patterns, unauthorized calls and overlarge model responses; it does not log prompts or secrets.
- `deploy/compose.yml` builds the adapter from source. Ollama is a pinned optional image with private model volume; neither service publishes a port. ERP has no `depends_on` edge to AI. Configuration examples remain disabled by default. [Operator guide](../../../services/ai/README.md) describes optional startup and pull.
- D09 records model/runtime license, version/digest, same-host data locality, no provider fee, 30-second timeout, 256-token output cap, storage/RAM budget and fallback. Model quality/peak RAM are explicitly deferred to live G10 checks.

- `docker compose -f deploy/compose.yml --env-file deploy/instances/a.env.example --profile apps --profile ai config --format json`: ERP depends only on `db-migrate`; AI/Ollama each have zero public ports and AI is only on `internal` network.
- `docker build -f services/ai/Dockerfile -t nexora-ai:p10-t01 .`: pass. Existing A/B/C ERP containers answered 200 for `/api/v1/health/ready` through their internal port with AI absent; public gateway returns 401 as designed.

## Retention / opt-out (P10-T06)

- Single operator flag `AI_PROMPT_RETENTION`: `none` (default) or `redacted`; `raw` and other values fail config validation. No settings UI.
- AI paths persist no prompt, model answer, internal token or canary. Only redacted structured audit metadata from T02/T03 stays in `platform.audit_log`; `none` opts out of any future prompt/answer transcript capture.

## Boundary

No model was pulled or run, so this evidence does not prove Vietnamese answer quality or measured model RAM. P10-T03/G10 must test a real model. Filtering known secret/contact patterns is defense in depth; P10-T02/T03 must form only safe tool facts and never feed raw documents or private fields to inference.
