# P03-T01 — platform schema và quyền DB

**Ngày:** 2026-11-19

**Nhánh:** `phase03/p03-t01-platform-schema`
**Trạng thái:** PASS cho phạm vi T01; G03 còn phụ thuộc T02–T08.

## Quyết định và thay đổi

- Giữ nguyên migration P01 `20261117000000_platform_baseline`. Migration bù `20261118020000_platform_core_audit_grant` giới hạn `correlation_id` và cấp `core_data` quyền `SELECT, INSERT` trên audit. `app_runtime` và `core_data` không có quyền UPDATE/DELETE audit; ERP runtime không ghi attachment/core_record.
- `services/core-data/repositories.mjs` nhận `PrismaClient` hoặc `Prisma.TransactionClient` do caller cung cấp. Version update dùng `WHERE id, version` và tăng version atomically. Không mở transaction phụ. Validation/authz API sẽ hoàn thành ở T07; file lifecycle ở T04–T05.
- CI chạy script `tests/platform/run-schema.sh` trên ba database PostgreSQL 17 cách ly: nâng cấp từ Phase 02, cài mới, và restore ảnh chụp trước nâng cấp. Bài test kiểm cột, constraint, unique, quyền DB bằng cả metadata lẫn thao tác bị PG từ chối.

Test còn chứng minh `app_runtime` bị từ chối UPDATE core_record và INSERT attachment, `core_data` bị từ chối UPDATE/DELETE audit. Không có bảng `inventory.stock_balance` trước P06. Hệ thống transaction nghiệp vụ Inventory/Outbox thật chưa tồn tại ở P03; T02 kiểm primitive atomicity, P04/P06/P07 phải bổ sung test tích hợp khi bảng tương ứng được tạo.

Để CI của nhánh Phase 03 chạy được trên nền Phase 02 vừa pull, task cũng bỏ các biến route/test không dùng, sửa kiểu `client_id` trong PartnerActor và chọn Python 3 khả dụng trên Windows/Linux cho JCS check. Các thay đổi này không đổi hành vi HTTP. CI hiện lắng nghe cả `phase-03` và `phase03/**`.
