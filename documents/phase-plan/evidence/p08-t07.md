# P08-T07 — Evidence và chất lượng lịch sử

Date: 2026-11-24. Branch: `phase-08`.

## Implementation

- Migration `20261124030000_trace_evidence` links a clean `platform.attachment` to a confirmed local trace event and its document. It stores SHA-256, visibility, creator, active/revoked state and keeps trace events append-only. Database guards reject mismatched document/event, unclean or quarantine file, wrong checksum and mutation of the source link. A link change or file scan/checksum change marks the public projection stale.
- ERP evidence API lists, attaches and revokes links under actor/batch scope. Staff can attach private/partner evidence from their own uploads; only Administrator can mark public, and only while approved policy exposes both timeline and evidence. `/trace` provides upload, scan-state check, attach, list, private download, revoke and projection rebuild controls. Core Data retains its existing authenticated private download policy.
- Passport timeline retains UTC `occurredAt` and `recordedAt` separately, issuer and source event ID. For receiving it reports sent and actual batch quantities without replacing either. Source checksum/document-version/quantity disagreement omits the unreliable event and sets `source_investigation`; missing remote links and receiving discrepancy remain explicit gaps. UI converts dates to `Asia/Ho_Chi_Minh` only for presentation.
- A public Passport mints a random 256-bit evidence capability after QR, policy, projection, document and clean-link checks. The URL expires after 60 seconds, contains no S3 credentials, and is rate limited by gateway. Core Data receives only a filtered read view; it checks the capability, current QR/policy/batch/projection/evidence/scan state and byte checksum before streaming from private storage. Expired grants are pruned by the worker.

## Boundary

The URL is an application-issued short-lived capability served by Core Data, not a direct S3 presigned URL. This keeps the private SeaweedFS endpoint and credentials off the browser and permits immediate revocation. Full A/B/C provenance verification is P09; operational quality issue workflow remains P12.
