## Security Audit Helper

`platform/audit/security-audit.ts` provides:
- `redact(value)` — strips JWT, Bearer tokens, and secret fields before logging.
- `actorSummary(actor)` — builds a safe log-safe summary (truncated sub, no PII).
- `auditDeny(actor, action, requestId)` — structured JSON warn for policy denies.
- `auditAccess(actor, action, outcome, requestId)` — structured JSON info for access.

**Output format:**
```json
{"service":"nexora-security-audit","timestamp":"2026-11-18T14:00:00Z","requestId":"req-abc","action":"admin:membership:manage","outcome":"deny","actor":{"type":"user","subPrefix":"a1b2c3d4…","roles":["staff"],"organizationId":"org-1"}}
```
