## Schema: system.partner

```sql
CREATE TABLE system.partner (
    id                  uuid PRIMARY KEY,
    issuer_instance_id  text UNIQUE NOT NULL,
    code                text UNIQUE NOT NULL,
    display_name        text NOT NULL,
    status              text NOT NULL DEFAULT 'active' CHECK (status IN ('active','suspended')),
    contact_email       text,
    created_by_sub      text NOT NULL,
    created_at / updated_at / version
);
```

## Schema: system.partner_connection

```sql
CREATE TABLE system.partner_connection (
    id                      uuid PRIMARY KEY,
    partner_id              uuid UNIQUE FK → system.partner,
    endpoint_url            text,       -- remote API
    outbound_token_url      text,       -- remote Keycloak token endpoint
    outbound_client_id      text,       -- remote grants to local
    outbound_secret_ref     text,       -- secret store reference (NOT plaintext)
    outbound_audience       text,
    inbound_client_id       text UNIQUE,-- local Keycloak client for this partner
    allowed_inbound_scope   text DEFAULT 'federation:write',
    status                  text CHECK IN ('active','rotating','disabled'),
    ...
);
```

## Trust Model

```
Partner Instance B (sender)
  → Keycloak B issues JWT (client_credentials, scope=federation:write, azp=partner-inbound-b)
  → JWT sent to Instance A gateway as Bearer token
  → Gateway (OIDC bearer_only) validates: issuer=A's Keycloak, audience=partner-inbound-b, sig, exp
  → App: resolvePartnerActor(claims, connectionRepo)
      → lookup inbound_client_id = claims.azp = "partner-inbound-b"
      → verify connection.status = 'active'
      → return PartnerActor{type:"partner", partnerCode:"B", ...}
  → Federation stub returns 202
```

**Attack vectors blocked:**
- C impersonates A: `issuer_instance_id` mismatch → OIDC rejects token
- Wrong audience: OIDC rejects
- Revoked client (disabled connection): `resolvePartnerActor` throws `PARTNER_CONNECTION_INACTIVE` → 403
- User token on M2M route: missing `azp` → `MISSING_CLIENT_ID` → 403
- Missing scope: `MISSING_SCOPE` → 403
