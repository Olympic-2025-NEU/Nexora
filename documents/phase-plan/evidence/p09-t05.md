# P09-T05 — External lot mapping và dependency gap

`federation.identity_mapping` gắn cặp `(origin_issuer_instance_id, origin_lot_id, sender_instance_id, sender_batch_id)` với local `catalog.batch` và inbox nguồn. `bindExternalLot` chỉ cho Staff/Administrator, kiểm tra source line nằm trong inbox đã xác thực và origin pair của local batch khớp chính xác. Cùng tên sản phẩm, SKU hoặc local lot code không là khóa mapping. Chưa có local batch thì inbox giữ external reference trong payload, không tạo master data giả. T06 gọi service này trong luồng nhận hàng.

`resolveInbox` tạo một trace event `partner_asserted` cho mỗi source line đã map. Summary có allowlist: issuer khẳng định, origin, sender batch, số lượng/unit, source document ID/type/version, upstream refs, schema/policy version. Không sao chép tên sản phẩm, buyer, file private hay raw document sang summary. `source_message_id` FK trỏ inbox; provenance `B` vẫn riêng với origin `A`. Khi parent chưa có trace local, `trace_link` giữ issuer-qualified `missing_ref`; khi parent đến/mapped, resolver cập nhật đúng link thành `partner_asserted`, không tạo history giả. Passport projection của local batch được đánh dấu `stale` để chính sách xuất bản quyết định nội dung được công khai ở T07.

Inbox chưa đủ mapping/parent ở `pending_dependency` với `UNKNOWN_LOT_MAPPING` hoặc `MISSING_UPSTREAM_EVENT`; ACK ban đầu là `pending_dependency` và replay trả nguyên ACK. Parent khác event/origin hoặc vòng dependency bị từ chối; parent sai origin đến muộn thì child được đánh dấu `rejected` với mã lỗi, giữ gap để điều tra. Resolver idempotent chạy sau inbound, sau binding và mỗi phút trong worker để phục hồi sau restart. Không thay đổi stock; xác nhận số lượng thực tế thuộc T06.

Kiểm chứng: `npm run test:platform:federation` trên disposable PostgreSQL áp dụng 29 migrations, gồm B→C trước parent, bind local batch, parent A đến muộn, reprocess lặp không nhân trace/link; cùng lot code khác issuer, vai trò viewer bị chặn, sender giả, cycle, parent sai origin bị đánh dấu. CI chạy bộ này thành job `platform-federation`. `npm test`, `npm run typecheck`, `npm run build:worker`, `npm run build`, ESLint và `npm run test:platform:trace` pass. Harness upgrade P08 bỏ migration mapping mới khỏi snapshot cũ, rồi áp dụng đủ migration theo thứ tự ở bước upgrade. Kịch bản parent relay trong test dùng một DB disposable để kiểm trạng thái resolver; G09 mới chứng minh chuỗi A/B/C thật với DB/realm riêng và HTTPS.
