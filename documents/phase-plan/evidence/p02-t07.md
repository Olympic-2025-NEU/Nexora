## Runbook: Create a Partner Receiver Client (B for A)

1. Log in to Keycloak admin console for Instance B: `https://<b-host>/realms/nexora`
2. Create client: `partner-inbound-a` (Service Account type, `serviceAccountsEnabled: true`)
3. Add scope `federation:write` to client scopes
4. Copy client secret → store in Instance B's secret store as `partner-inbound-a-secret`
5. In Instance A: set `PartnerConnection.inboundClientId = "partner-inbound-a"` via admin API
6. Test: curl with client credentials token from B → POST /api/v1/federation/events on B → 202

**Rotate/Revoke:**
- Rotate: generate new secret in Keycloak → update `outbound_secret_ref` → set `status = 'rotating'` during transition → verify → set `status = 'active'`
- Revoke: set `PartnerConnection.status = 'disabled'` in DB → `resolvePartnerActor` returns 403 immediately (no token blacklist needed)
