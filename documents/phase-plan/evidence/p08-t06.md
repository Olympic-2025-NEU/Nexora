# P08-T06 — QR token và public Passport

Date: 2026-11-24. Branch: `phase-08`.

## Implementation

- `qr_token` stores SHA-256 of a 32-byte random base64url token, policy version, expiry (30 days) and a unique hashed issuance key. Raw URL is returned only on first 201; retry with the same key is 409. The URL is `PUBLIC_BASE_URL/passport/{token}`, with no batch or document UUID. Issue requires an approved active policy/projection, matching checksum, available batch and Administrator or in-scope Staff. Revoke records audit and immediately removes access. A database trigger revokes active tokens when projection is revoked or its policy version changes.
- Public API GET/HEAD checks token state/expiry, current batch quality, approved policy, active projection, exact seven-field allowlist and checksum on every request. Invalid, unknown, expired and revoked tokens return the same 404 without metadata. Response is `no-store`, `no-referrer`, `noindex`; errors do not expose database details. Private QR routes use authenticated actor and row scope.
- Gateway exposes `/api/v1/public/passport/*` and `/passport/*` as anonymous GET/HEAD at 30 req/s, burst 15 per remote address, with 429 rejection. The private `/api/v1/*` route retains OIDC. `/trace*` is exposed for the existing trace UI. Mobile `/passport/{token}` shows public source issuer, local verification state, times, gaps and an explicit statement that this is not a quality certificate. `/trace` allows policy draft/approval for Administrator, QR generation, PNG download, print and revoke.
- The generated OpenAPI, schema, payload and security documents now describe token format, lifecycle, status, rate and privacy. Source/license inventories include the QR encoder and scan-test decoder.

## Boundary

The PNG decode test proves the QR carries the intended URL; a physical mobile-device scan and externally reachable HTTPS deployment still belong to an environment smoke test. T07 adds clean/public evidence and richer timeline provenance. A/B/C source verification remains P09.
