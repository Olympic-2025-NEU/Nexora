# P03-T03 — audit bất biến và correlation

**Ngày:** 2026-11-19

**Nhánh:** `phase03/p03-t03-audit-correlation`

**Trạng thái:** PASS cho adapter/API T03; tích hợp action nghiệp vụ và G03 còn ở các phase tiếp theo.

## Đã làm

- `prismaAuditRecorder.record(tx, entry)` dùng đúng TransactionClient của caller. PostgreSQL cấp thời điểm; adapter ghi user `sub` hoặc service `client_id`, action, target, outcome `success`, request/correlation ID và snapshot allowlist. Giá trị lạ/PII/token bị bỏ trước INSERT, ID request có dấu `.` hoặc quá dài bị từ chối.
- `auditDeny` và `auditFailure` ghi structured security log riêng bằng reason code. Request ID không hợp lệ bị bỏ; không ghi error message, token, raw detail hoặc full user sub. `resolveActor` cũng không ghi full sub ở log/error.
- `GET /api/v1/audit-logs` dùng Bearer auth thật của P02, membership DB và policy Administrator, parser chỉ nhận filter allowlist, limit tối đa 100, cursor opaque. Repository Prisma trả metadata cần điều tra, không trả summary JSONB. OpenAPI/contract bổ sung filter `requestId`, `targetId` text và `correlationId` trong item.
- Runbook [`audit-retention.md`](../audit-retention.md) quy định retention online mục tiêu 365 ngày, export/restore kiểm trước purge và quyền migrator riêng. P03 chưa tự xóa audit.
