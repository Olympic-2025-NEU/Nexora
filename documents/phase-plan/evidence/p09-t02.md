# P09-T02 — Federation envelope và version negotiation

- Envelope chung và ba schema theo event ở `contracts/events/`; `additionalProperties:false` tại envelope và mọi object lồng nhau. Event schema khóa event type, source document và cấm field của event khác.
- Validator dùng chung sender/receiver ở `contracts/events/federation.ts`: giới hạn raw payload 256 KiB, duplicate JSON key, version, decimal, unit, quantity totals, recipient/issuer, JCS SHA-256 và clock-skew warning. `UNSUPPORTED_SCHEMA`/`UNSUPPORTED_EVENT_TYPE` là 422; `PAYLOAD_TOO_LARGE` là 413. Replay helper phân biệt ACK cũ, message ID/hash conflict và event ID mới conflict; lưu inbox thuộc T04.
- Fixture A→B→C, invalid và replay trong `contracts/events/fixtures/manifest-v1.json`; hash Node/Python cố định. OpenAPI federation envelope ở `contracts/openapi/nexora-v1.yaml`.
- Kiểm chứng: `npm run test:contracts`, `npm run typecheck`, `node --test --require tsx/cjs contracts/events/federation.test.ts`. Test sender và receiver cùng chạy fixture/hash độc lập, unknown version, decimal sai, payload quá lớn, private field, replay cùng ID/hash và ID/hash khác.
