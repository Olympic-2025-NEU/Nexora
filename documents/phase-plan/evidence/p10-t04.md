# P10-T04 — AI Draft chứng từ có human review

Date: 2026-11-26. Branch: `phase10/p10-t04-draft-review`. Depends on T02/T03. Covers AC-11 only. Scope: receipt Draft; issue Draft deferred to T04b (R1).

## What was built

- Deterministic orchestration in `contexts/ai/application/draft-receipt.ts`: Vietnamese pattern extraction for lot code, quantity, unit and warehouse hint; actor-scoped T03 lot resolution with `ambiguous`; `getStock`/`getTrace` fact bundle; four R8 warnings; server-computed `proposalId`; two audit entries; creation through the existing T02 `createReceiptDraft` tool. No adapter, model output or conversation store.
- Two-phase HTTP surface: `POST /api/v1/ai/draft` returns `{status:"proposed", fields, sources, warnings, proposalId}` and creates nothing; `POST /api/v1/ai/draft/create` calls the tool only after human click, with `proposalId` as idempotency key. Aliases `/ai/draft` and `/ai/draft/create` follow T03. `composition/ai.ts` resolves current Bearer actor, request id and warehouse scope for both routes.
- DraftReview section on `/assistant` in `app/assistant/_components/assistant-draft.tsx`: separate tab next to Tra cứu, editable fields, source chips, warnings, user-only note, disabled double-submit, phase banners, three-step copy, single `Tạo Draft` button, and `Mở phiếu trong M03 →` deep link. T03 answer card has `Soạn phiếu nhập từ lô này` prefill with quantity left blank.
- Audit extension in `platform/audit/prisma-audit-recorder.ts`: allowlisted `proposalId`, `warehouseId`, `batchId`, `draftDocumentId` and warning codes in `ai.draft.*` summaries. Raw request text and note never enter audit.
- Tests and fixtures: `contexts/ai/application/draft-receipt.test.ts` (6 unit tests), `tests/ai/draft-receipt.golden.test.ts` (3 golden tests), `tests/ai/draft-adversarial.test.ts` (6 adversarial tests), `tests/ai/draft-fixture.ts` with seeded A/B/C-style lots, duplicate `LOT-A-001`, `inspect` batch and actor `dev-staff`. Scripts `test:ai:draft` and `test:ai:adversarial` added to `package.json` and wired into `npm test`.
