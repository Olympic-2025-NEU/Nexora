### 8. Keycloak bootstrap

`deploy/keycloak/bootstrap.mjs`:
- `ensureUser()` and `assignRole()` helpers.
- `assignMfaRequiredAction()` — sets `CONFIGURE_TOTP` on administrator/approver users.
- Optional `KC_ADMIN_USERNAME`/`KC_ADMIN_PASSWORD` → creates administrator user with MFA.
- Optional `KC_APPROVER_USERNAME`/`KC_APPROVER_PASSWORD` → creates approver user with MFA.
