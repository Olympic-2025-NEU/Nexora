# P09-T03 — Outbound delivery

- `contexts/trading/application/transfers.ts`: Confirmed phát envelope bền vững và due ngay, không HTTP trong command transaction. Business receipt outbound từ receiving vẫn giữ đến T06.
- `workers/federation-outbound.ts`: worker lấy connection active theo recipient, giải secret ref, client credentials token, POST gateway, timeout, refresh sau 401, kiểm ACK và ghi attempt đã lọc. Chỉ ACK hợp lệ mới set transfer `technical_ack`; dispatcher đánh dấu outbox `delivered` sau handler thành công. 409/413/422 hoặc credential revoke vào dead-letter; mạng/5xx/ACK lỗi retry theo dispatcher. `platform/operations/retry-dead-letter.ts` đã kiểm quyền, ghi audit và được dùng lại.
- `prisma/migrations/20261124040000_federation_delivery_attempt/migration.sql`: FK outbox, unique attempt, CHECK ACK, grant tối thiểu. Admin retry đặt lại outbox counter, nên delivery attempt dùng số tăng độc lập dưới row lock.
- UI Transfers hiển thị pending/retry/ACK/lỗi, timestamp ACK, mã lỗi an toàn và nút admin retry. Hướng dẫn kết nối/secret ở `deploy/federation-outbound.md`.
- Compose worker nhận tùy chọn `PARTNER_OUTBOUND_CLIENT_SECRET` cho demo local (chỉ trong instance env bị Git ignore); production dùng file secret mount theo runbook. `docker compose ... config -q` với A template và `node --test deploy/config.test.mjs` đều đạt.
- Kiểm chứng đã chạy: `npm run test:federation:outbound` (5/5: B offline, ACK mất, restart, ACK sai, token refresh/revoke, redaction, no HTTP in TX); `npm run test:platform:outbox` (10/10: backoff/lease/dead-letter và attempt retry→ACK lưu PG); `npm run test:platform:trading` (26/26 + conformance 8/8: Confirmed tạo outbox due ngay, ACK cập nhật transfer state trên PG, không movement lần hai); `npm run test:platform:schema` (fresh/upgrade/constraints/grants 4/4); `npm test`, `npm run build:worker`, `npm run typecheck`, `npm run build`, `npx prisma validate` đều đạt.
- Chưa có live A→B ACK vì receiver T04 hiện là stub. Đây là dependency đã định trong phase, không coi mock là bằng chứng business receiving.
