# Federation outbound v1 — vận hành T03

1. Mỗi instance giữ một `system.partner` có `issuer_instance_id` bằng ID instance nhận và `system.partner_connection` active. `endpoint_url` trỏ tới **gateway HTTPS** của instance nhận tại `/api/v1/federation/events`; `outbound_token_url` là token endpoint của realm instance nhận. Cả hai URL phải qua kiểm tra SSRF/HTTPS. Không dùng địa chỉ DB/Keycloak admin trực tiếp làm event endpoint.
2. Instance nhận cấp client M2M cho bên gửi trong Keycloak với scope `federation:write` và audience phù hợp. `outbound_client_id` và `outbound_audience` nằm trong connection; `outbound_secret_ref` chỉ có dạng `env:VARNAME` hoặc `secret:name`. Worker đọc biến môi trường **riêng của worker** hoặc file `/run/secrets/name`; nội dung secret không nằm trong DB/Git/log. Với Compose demo, đặt `PARTNER_OUTBOUND_CLIENT_SECRET` trong file instance env bị Git ignore và lưu `env:PARTNER_OUTBOUND_CLIENT_SECRET` ở connection. Với production, dùng `secret:name` và mount file vào worker bằng Compose override/secret manager. Provision và rotation credential do operator thực hiện; nếu thiếu/revoke, attempt trở thành `permanent_failure` và outbox dead-letter.
3. Transfer Confirmed ghi envelope `transfer.announced.v1` vào `platform.outbox_message` trong cùng transaction. Worker lease message, lấy token bằng client credentials, POST đúng payload/message ID tới receiver với timeout 5 giây token và 10 giây event. 401 từ event refresh token một lần. 202 chỉ được coi là delivered nếu ACK có đúng `messageId`, UUID `ackId`, timestamp và status `validated`/`pending_dependency`. ACK kỹ thuật không cộng tồn và không phải business receipt.
4. B offline, timeout hoặc mất response: outbox chuyển `retry_due`, giữ nguyên envelope; dispatcher dùng backoff có jitter, tối đa 8 attempts rồi dead-letter. `federation.delivery_attempt` giữ host, HTTP status, mã lỗi, thời lượng và ACK metadata; không ghi token/secret/body response. Nếu nhận ACK mà worker chết trước mark delivered, retry cùng message ID/hash an toàn nhờ inbox dedupe T04.
5. Trang Transfers hiện chờ gửi, thử lại, ACK hoặc lỗi. Admin có thể retry dead-letter qua `POST /api/v1/admin/retries`; endpoint kiểm quyền và ghi audit. Trước retry phải sửa nguyên nhân (credential, endpoint, version hoặc policy). `attempt_no` trong bảng delivery tăng qua các lần admin retry.

**Giới hạn theo phase:** inbound `/api/v1/federation/events` hiện là stub; nó chưa tạo ACK đúng hợp đồng. T04 sẽ bổ sung inbox/ACK thật. T03 được kiểm thử bằng receiver giả lập và migration trên PostgreSQL độc lập; A→B live chỉ hoàn tất sau T04 và credential/HTTPS được provision.
